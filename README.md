# 英语词汇5500
## 关于本书
《英语词汇5500》是一本为考研英语（一 / 二）备考整理的 EPUB 词汇书。
大多数词汇书从 A 背到 Z，很多人背到 C 就放弃了。这本书换了一种编排方式：先按**基础 → 提高 → 核心 → 熟词僻义 → 主题热词 → 必考词组 → 低频 → 不考**八个层级拆开，把最该先背的高频词放在前面，把明确不考的词单独列出，让有限的时间花在更可能考的地方。
每个词条包含 **单词 · 音标 · 词性 · 中文释义 · 双语例句**；核心词条另附 **【真题链接】**，标注年份与英语一 / 二 Text 出处。第三部分共 12 个 Unit，每个 Unit 配一套练习（写词、选词填空、派生词），每套练习后附参考答案。
## 特色
- **八级分层编排**：基础 → 提高 → 核心 → 熟词僻义 → 主题热词 → 必考词组 → 低频 → 不考，先高频后低频，避免无效背诵。
- **近 3,000 条双语例句**：全书 2,883 条例句，英文原句配中文翻译，在语境中记词义和用法。
- **540 处真题链接**：核心词条标注考研英语真题出处，方便对照原文、感受考法。
- **熟词僻义专章**：把「常义 / 僻义」对照排列，专治阅读里「每个词都认识，句子却读不懂」。
- **主题热词分类**：政治法律、地理天文、生物医学、网络通信、信息技术、经济、职业 7 大类，按阅读题材成组记忆。
- **词组按频率分级**：441 条必考词组按真题出现频率分为 ≥5 次、≥3 次、=2 次、=1 次四档，优先背高频。
- **12 套单元练习**：每个 Unit 配写词、选词填空、派生词练习，附参考答案，学完立刻自测。
